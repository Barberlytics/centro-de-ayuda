# What to do if the code is wrong or expires

**In short:** each code works once and only for a short time. If the app doesn't accept it, get a new one with **Resend code** and enter the latest one you received.

## What to check

1. Enter the **most recent** code. If you asked for several, only the last one works.
2. Make sure no digit is missing. If the field is left empty, the app says “This field is required.”
   ![The empty Code field with the app's message](/assets/es/acceso-y-cuenta/confirmar-el-codigo/codigo-vacio.png)
3. If a long time has passed since you asked for it, tap **Resend code** and use the new one.
4. If the number was a different one, tap **← Back**, correct it and ask for the code again.

## What the screen says

> [!WARNING]
> If you keep failing, the screen may show “The user has been blocked for security reasons.” See [It says “The user has been blocked for security reasons”](/ayuda/acceso-y-cuenta/usuario-bloqueado-por-seguridad).

| Text | What it means |
|---|---|
| “This field is required” | You didn't enter the code |
| “This field is too short” | Some digits are missing |

> [!NOTE]
> The exact message shown when the code is wrong or has expired, and how many attempts the app allows before blocking, isn't documented yet: it will be checked with a real phone.

## Frequently asked questions

**How long does a code last?**
It isn't documented yet. If in doubt, get a new one.

**It keeps saying it's wrong.**
Get a new code, wait for it to arrive and enter it without spaces. If it still fails, write to support from **Contact us**.
