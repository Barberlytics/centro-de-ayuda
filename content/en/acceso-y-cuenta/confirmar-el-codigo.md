# Confirm your number with the code

**In short:** after **Sign In**, the **Confirm number** screen asks for a code we sent to your phone.
Enter it in **Code** and tap **Confirm**. If it didn't arrive, tap **Resend code**.

![The Confirm number screen with the Code field and the Confirm and Resend code buttons](/assets/es/acceso-y-cuenta/confirmar-el-codigo/pantalla.png)

## Steps

1. Read the message: “We've sent a code to your phone to check that it's you.”
2. Find the code on your phone and enter it in the **Code\*** field.
3. Tap **Confirm**.

## If the code doesn't arrive

- Tap **Resend code** to get a new one.
- If you typed your number wrong at the start, tap **← Back** to go back and correct it.
- If you still can't get in, write to us with the help button at the bottom right. See
  [Contact support from the sign-in screen](/ayuda/acceso-y-cuenta/contactar-a-soporte-desde-la-entrada).

## Errors you may see

> [!NOTE]
> If “The user has been blocked for security reasons” appears after several wrong codes, see [It says “The user has been blocked for security reasons”](/ayuda/acceso-y-cuenta/usuario-bloqueado-por-seguridad).

| What the screen says | What it means | What to do |
|---|---|---|
| “This field is required” | You tapped **Confirm** without entering the code. | Enter the code you received and tap **Confirm** again. |

![The “This field is required” message below the Code field](/assets/es/acceso-y-cuenta/confirmar-el-codigo/codigo-vacio.png)
