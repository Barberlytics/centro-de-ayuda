# Resend the code

**In short:** on the **Confirm number** screen, below the **Code\*** field, there's the **Resend code** button. Tap it if the message didn't arrive.

## Steps

1. Enter your phone on the sign-in screen and tap **Sign In**.
2. On **Confirm number**, wait a moment for the message to arrive.
   ![The Confirm number screen with the Code field and the Resend code button](/assets/es/acceso-y-cuenta/confirmar-el-codigo/pantalla.png)
3. If it doesn't arrive, tap **Resend code**.
4. Enter the new code in **Code\*** and tap **Confirm**.

If you typed the number wrong, tap **← Back** and correct it.

> [!NOTE]
> How long the message takes, how many times it can be resent and what message the app shows when you resend isn't documented yet: it will be checked with a real phone.

## Frequently asked questions

**Why isn't the message arriving?**
Check that the country and the number are right (**+57** for Colombia) and that your phone has signal. Then use **Resend code**.

**Can I get the code another way?**
The screen only offers resending by text message. If you don't receive it, use **Contact us** ([Contact support from the sign-in screen](/ayuda/acceso-y-cuenta/contactar-a-soporte-desde-la-entrada)).
