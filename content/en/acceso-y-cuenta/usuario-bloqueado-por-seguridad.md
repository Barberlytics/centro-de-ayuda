# It says “The user has been blocked for security reasons”

**In short:** on the **Confirm number** screen a red notice appears: “The user has been blocked for security reasons.”
It's a protection for your account. Asking for another code doesn't lift it: you have to write to us so we can look into what happened.

![The Confirm number screen with the “The user has been blocked for security reasons” notice](/assets/es/acceso-y-cuenta/usuario-bloqueado-por-seguridad/aviso.png)

## Why it happens

The notice appears after you enter a code that doesn't work. So it happens when several wrong codes
are tried in a row. It's a security measure so that no one else can guess your account's code.

## What to do

1. Don't keep trying codes.
2. Tap the help button, the circle with a question mark at the bottom right. **Contact us** opens.
3. Fill in the five fields: **Full name\***, **Company\***, **Email\***, **Phone\*** and **Tell us what happened\***.
4. In **Tell us what happened\*** write the phone you're trying to sign in with and that you got “The user has been blocked for security reasons.”
5. Tap **Send**.

The details of the form are in [Contact support from the sign-in screen](/ayuda/acceso-y-cuenta/contactar-a-soporte-desde-la-entrada).

> [!TIP]
> Use an email you can actually open. It's where they'll reply to you.

## Before you write, check

- That the country on the little flag and the number are yours ([Choose your phone's country](/ayuda/acceso-y-cuenta/elegir-el-pais-del-telefono)).
- That you're entering the last code you received ([What to do if the code is wrong or expires](/ayuda/acceso-y-cuenta/codigo-incorrecto-o-vencido)).

## Frequently asked questions

**Did I lose my account or my data?**
No. The block only stops you from signing in; your barbershop and its information stay as they were.

**Does Resend code help?**
It doesn't lift it. The notice stays on the screen.

**How long does it take to be resolved?**
It isn't documented yet.
