# A barber's code

**In short:** every barber has a **Code** in their record, in the **Personal information** block of the **Profile** tab, next to their **Phone number** and their **Email**. It's sensitive information about that person: don't share it or copy it outside the app.

## Where it is

1. Tap **Team** in the menu.
2. Under **Barbers**, tap **Actions** › **View Commission barber** (or **View Rent barber**) on the person's row.
3. In **Profile**, in the **Personal information** block, you'll find the **Code**.
   ![The Profile tab of the record with the Personal information block](/assets/es/equipo/ficha-de-un-barbero-perfil/ver.png)

> [!WARNING]
> Treat the code like a password. Only people who can open the barber's record can see it.

> [!NOTE]
> What the code is for and where it's used isn't documented yet. It also hasn't been checked whether it can be changed from **Edit**. It will be completed with the Barberlytics team.

## Frequently asked questions

**Does the barber need the code to sign in to the app?**
To sign in they use their phone number and the code that arrives by text message. See [Sign in](/ayuda/acceso-y-cuenta/ingresar). Whether the **Code** in the record plays a part in anything else isn't documented yet.

**Can I change it?**
It hasn't been checked yet. In the record in view mode it's only displayed.

**Who can see it?**
Anyone with **View** in **Team**: with the factory permissions, the owner, the location administrator and the commission barber.
