# Create a variable expense

**In short:** in **Expenses**, tap **Actions › Create variable expense**, type the **Name** and the **Amount** and tap **Create**. It has no frequency because it's a one-time expense.

## Steps

1. Tap **Expenses** in the menu.
2. At the top right, tap **Actions** and choose **Create variable expense**. The “Create variable expense” screen opens.
   ![The Create variable expense form: Name, Amount, Description, Add photos and the Create button](/assets/es/gastos/crear-un-gasto-variable/formulario.png)
3. Type the **Name**, for example “New towels.”
4. Type the **Amount**, for example 180000.
5. If you want, type a **Description** (“Twelve towels for the downtown location”).
6. If you want to keep the receipt, tap the **+** under **Add photos - 0/3**. You can add up to 3 photos.
7. Tap **Create**.

To leave without saving, tap **Cancel** at the top right.

**Name\*** and **Amount\*** are required.

> [!NOTE]
> What the app shows right after you tap **Create** and how an uploaded photo looks still need to be checked with a test expense.

## Frequently asked questions

**I paid for something that will happen again. Do I enter it as variable?**
Better as fixed, so it has its **Frequency**. See [Fixed and variable expenses](/ayuda/gastos/gastos-fijos-y-variables).

**Where does the expense go after I create it?**
In **Expenses**, on the **Variable** tab, with its name and amount.

**Can I change a variable expense to fixed later?**
That option wasn't there. In **Edit** you change the name, amount, description and photos of the same type of expense.
