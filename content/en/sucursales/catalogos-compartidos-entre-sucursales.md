# Services and products: created once and activated per location

**In short:** your service catalog and your product catalog belong to the whole company. Each location **activates** the ones it uses.

## Services

- Services are created in **Services › Actions › Create Service**.
- For a location to use them, go to **Actions › Activate services**. The screen says: “Select the services you want to import by turning on the service with the switch.”
- For example: a catalog of 30 services, and a location that activates only the ones it offers.

## Products

- Products are created in **Products › Actions › Create product**.
- For a location to sell them, go to **Actions › Activate barbershop products**.

## What does apply to all of them

Creating a service or a product doesn't put it in every location right away. You have to activate it in each one.

> [!NOTE]
> With the **commission barber** profile, the **Services & Products** group doesn't appear in the menu. That group is for whoever manages the barbershop.

## Frequently asked questions

**I created a service and it doesn't show up in my location.**
It still needs to be activated. See [Activate services in a location](/ayuda/sucursales/activar-servicios-en-una-sucursal).

**Do I have to create the service again to open another location?**
No. You create it once and activate it in the new location.
