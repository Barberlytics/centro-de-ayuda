# Create a location

**In short:** in **Settings › Locations**, tap **Create Location**, fill in the fields marked with an asterisk and tap **Create**. The location starts out empty: afterward you activate the team, the services and the products in it.

## Steps

1. Tap **Settings** in the menu and open **Locations**.
2. Tap **Create Location**, at the top right of the “Locations list.”
   ![The Create Location form with all its fields](/assets/es/sucursales/crear-una-sucursal/formulario.png)
3. Fill in the fields. The ones with an asterisk are required.
4. Tap **Create**. To leave without saving, tap **Cancel**.

## The fields

| Field | Required | What to put |
|---|---|---|
| **Location name\*** | Yes | What you call it day to day, for example “Sucursal Norte” |
| **Company name\*** | Yes | Your company's name |
| **ID\*** | Yes | The location's ID |
| **Company\*** | Yes | The company it belongs to |
| **Country\***, **State\***, **City\*** | Yes | Where it is |
| **Address** | No | The shop's address |
| **Postal code** | No | |
| **Phone\*** | Yes | The location's mobile or landline number |
| **Currency\*** | Yes | The currency that location charges in (COP, USD…) |
| **Language\*** | Yes | The language that location uses with its clients |
| **Time zone\*** | Yes | The time its calendar is shown in, for example America/Bogota |
| **Description** | No | A sentence about the shop |
| **Photos - 0/5** | No | Up to five photos |

**Currency**, **Language** and **Time zone** belong to each location: you can have a location in Colombia with COP and another in the United States with USD. [What changes from one location to another](/ayuda/sucursales/que-es-propio-de-cada-sucursal) explains it.

> [!NOTE]
> This article was written by reading the form without tapping **Create**. What the app shows right afterward (a message, where it goes back to) and what validations each field has will be completed once a test location is created.

## After creating it

A new location starts with “0 Barbers” and no services or products. The full order is in [Opening a new location](/ayuda/sucursales/abrir-una-sucursal-nueva):

1. Choose the new location in the selector at the top.
2. **Team › Actions › Activate team in this location**.
3. **Services › Actions › Activate services**.
4. **Products › Actions › Activate barbershop products**.
5. **Team › Working hours** to set a schedule for each barber.

## Frequently asked questions

**How many locations can I create?**
How many your plan allows isn't documented yet.

**Can I change the currency later?**
The **Edit** form has the same **Currency\*** field. What happens to prices that already exist isn't documented: check before you change it.

**Does the new location inherit the Settings?**
Permissions, taxes, tips, commissions and payroll belong to the whole company and look the same in any location. See [General settings and per-location settings](/ayuda/sucursales/ajustes-generales-y-por-sucursal).
