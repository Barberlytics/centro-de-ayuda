# Lista de espera: cuánto tiene el cliente para aceptar y para llegar

**En resumen:** cuando se libera una hora y se le ofrece a un cliente de la lista de espera, tiene un tiempo para aceptarla (**Minutos para aceptar**) y, una vez aceptada, un tiempo para llegar a la barbería (**Minutos para llegar**). Los dos se eligen en **Configuración › Agendamiento online**.

## Dónde está

**Configuración › Configuración de la cuenta › Agendamiento online**, bloque «Lista de espera»: «Establezca el límite de tiempo para que un usuario acepte una cita cuando esté en la lista de espera. Determine el límite de tiempo para que un usuario llegue a la peluquería una vez que haya aceptado la cita de la lista de espera.»

![El bloque Lista de espera con Minutos para aceptar y Minutos para llegar](/assets/es/agendamiento-online/tiempos-de-la-lista-de-espera/bloque.png)

## Los dos tiempos

| Ajuste | Opciones |
|---|---|
| **Minutos para aceptar\*** | **15 minutos**, **30 minutos**, **45 minutos**, **60 minutes** |
| **Minutos para llegar\*** | **15 minutos**, **30 minutos**, **45 minutos**, **60 minutes** |

Elige y toca **Guardar** al final de la página.

## Ejemplo

Con 15 minutos para aceptar y 30 para llegar: a las 3:00 p. m. se cancela una cita y a Carlos, que estaba en la lista de espera, se le ofrece el hueco. Tiene hasta las 3:15 p. m. para aceptarlo. Si acepta a las 3:10 p. m., tiene hasta las 3:40 p. m. para llegar.

> [!NOTE]
> Por dónde recibe el cliente el aviso y qué pasa si no acepta o no llega a tiempo todavía no está comprobado.

## Preguntas frecuentes

**¿Cómo anoto a alguien en la lista de espera?**
Desde el calendario. Mira [La lista de espera: anotar a un cliente cuando no hay hueco](/ayuda/calendario/lista-de-espera).

**¿Qué tiempo me conviene?**
Si tu barbería está en una zona donde la gente llega caminando, 15 minutos para llegar suele bastar. Si tus clientes vienen en carro desde lejos, dale más.
